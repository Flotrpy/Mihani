One desktop console for every AI coding agent you run.

Mihani combines a real terminal, live Git status, and multi-agent orchestration into a single native app for Windows and macOS — so you can launch, watch, and hand off between agents without juggling a dozen terminal windows.

Security notes

No freeform remote input

Remote control's action set is a closed enum — start/stop/pause/ restart, view output, view Git status/diff, run your configured tests, or request a commit + push. There is no "send text" or "run shell command" action, so a remote client can never execute arbitrary input, by construction rather than by policy.

Commits and pushes need local approval

A remote "request commit & push" only opens Mihani's existing commit UI on your machine for you to review and confirm — it never commits or pushes on its own.

Secrets stay in your OS keychain

GitHub tokens are stored via your platform's native keychain, never written to app config or disk.

Custom agents require explicit trust

A user-defined agent command needs a "Trust & Run" confirmation before its first launch, and custom agents are never exposed to the remote-control action set — only built-in agents can be started remotely.
